戦術(ガンビット)

「HPが25%を切ったら下がる」「固有能力が撃てるなら一番近い敵に撃つ」のような指示を並べて、戦闘中の動きを決める仕組み(ガンビット)です。

画面ではこの仕組みを「ガンビット」と呼びます。このサイトでは、ガンビットの1行(条件+行動)を「指示」と呼びます。隊形に慣れてから手を付ける、中級者向けの調整です。

ダンジョンの中では直接操作できません。出撃前に組んだ指示どおりに探索者が動き、プレイヤーはそれを見守ります。勝敗を分けるのは、指示を組むこの準備です。

どこで設定するか

  • 日本語版では、出撃画面の「ガンビット」タブと、訓練場の「ガンビット」タブで設定します。画面で確認 作戦、引き返す時、職業別のガンビット、探索者ごとのガンビットがここにまとまっています。出撃画面には「名簿全体のガンビットを訓練場で変える」というリンクもあります。
  • 探索者ごとのカードに「既成のセットから…」「初期化」「攻撃役に写す」のボタンがあります。画面で確認
  • 「すべての部屋」と「最後の部屋」を切り替えて、ボス部屋だけ別のガンビットにできます。画面で確認
  • カードの「既成のセットから…」から、役割ごとの既製セットを読み込めます。白紙から組むより、既製セットを改造するほうが早いです。推論
  • 行の下には「戦闘での〇〇の動き」という要約が出て、探索者が実際にどう動くかを文章で確認できます。

仕組み: 上から順に読まれる優先リスト

探索者はルールのリストを上から順に見ていき、条件を満たした最初の指示を実行します。1行は「条件+行動(+標的)」でできています。

層中身
作戦(battle plan)の行隊の方針。各探索者の指示の上に重なり、探索者の指示を置き換えはしません。0.306 から、作戦はギルド全体だけでなく役目(名簿のグループ)ごとにも決められ、隊の中で人数が最も多い役目の作戦が使われます。単一出典推論(PATCH の post を役目と読んだもの)
探索者ごとの行(5行)探索者1人ひとりのルール。ここが本体です。
クラス固有の指示クラスごとに1つずつある専用の指示と、固有能力(signature)。0.306 から、クラス別の指示もギルド全体か役目ごとに決められます。単一出典

行の種類によって読まれ方が違います。

  • 行動の行(攻撃・回復・技など): 上の行が先に成立すると、下の行は実行されません。
  • 構え・盾・地形の行(stance / shield / ground): 行動の行とは別枠で読まれるので、「常に攻撃」の行より下にあっても働きます(0.303で表示の誤りが直りました)。
一番多い失敗: 技が一度も出ない
技のアイコンが「準備完了」になっていても、それを選ぶ行がなければ技は出ません。「条件: 常に(always) → 攻撃」の行が技の行より上にあると、毎回そこで決まってしまい、技まで順番が回ってきません。開発者の説明(ITCH)もこの点で、技の行はリストの上のほうに置くのが原則です。行動の行が絶対に実行されない位置にあると、エディタに「can never fire」と表示されます。

確認できている条件・行動・標的

説明文は「彼らの『もし/ならば』の戦闘規則。上から読み、最初に当てはまったものが発動する。(気の強い性格は、戦いの熱の中でこれを覆すことがある。)」です。行の頭の行動は、退却・盾・挑発・解き放つ・打つなど。最後の行は「それ以外は、最も傷ついた敵を攻撃する」です。条件の選択肢は分類ごとに並んでいます。

分類選択肢の例
生存体力が25%を割ったら退く(倒れる前に戦いから引かせる)
固有能力を解き放つ数で劣るとき、最も近い敵に/癒し手と召喚者に先に/最も打撃の強い敵に/体力の最も多い敵に

地形を活かす柱か壁を自分と敵のあいだに挟む/癒し手から見える位置にいる

条件の分類(ドロップダウンの見出し)は職業の役割ごとに次のとおりです(0.307)。画面で確認

役割分類
盾役生存、戦線を守る、味方をかばう、攻撃、攻めに出る、足場を固める、力を温存する、初手で攻める、[職業]にしかできない、地形を活かす、隊形を保つ
攻撃役生存、固有能力を解き放つ、攻撃、攻めに出る、足場を固める、力を温存する、初手で攻める、[職業]にしかできない、地形を活かす、隊形を保つ

行の頭の短い表示との対応は、生存=退却、味方をかばう=盾、戦線を守る=挑発、固有能力を解き放つ=解き放つ、回復=癒やす、攻撃=打つ です。プレイ報告

盾役の既成セットの例: ①退却(体力20%を割ったら) ②盾(敵が狙っている味方の前に立つ) ③④挑発(数で劣るとき) ⑤挑発(挑発が使えるたびに) ⑥それ以外は最も傷ついた敵を攻撃。

ガンビットの種類と働き 画面で確認

行の頭に付く種類と、画面の「各種ガンビットの働き」の説明です。

種類画面の説明
退却いちばん近い敵から下がる。隅ではなく仲間のほうへ引く。戦いから離れるわけではなく、動いているあいだは攻撃しない。
盾かばっている仲間に入る攻撃の50%を肩代わりし、自分の体力が30%を下回ると止める。
挑発盾役の固有能力(挑発の咆哮・踏みとどまれ)を使う。近くの敵の注意を奪い、隊の他の者から引き剥がす。消費20、その後6秒は再使用できない。
解き放つ攻撃役の固有能力を使う。例: 火球は対象の周囲すべてを一度に打つ(消費25、その後4秒)。抉り斬りは重い一撃を叩き込む(消費30、その後4秒)。
癒やす癒し手の固有能力を使う。細く流し続ける回復よりはるかに大きく味方を癒やす。例: 鼓舞の歌(消費25、その後2秒)、再生(消費20、その後1.5秒)。
打つごく普通の攻撃。ほかの構えはすべてこれを基準に測られる。火力はそのまま、「息」も通常の速さで減り、手加減はない。

「打つ」の説明には続きがあります。ほかのギルドが相手のとき、相手の盾役の挑発は、ガンビットが何を指定していようと、数秒間この探索者の攻撃をその盾役へ向けさせる。また「殿軍」で戦うギルドは、後列を前列の後ろに保つ。画面で確認

画面で見た既成のセットの例(「戦闘での〇〇の動き」の文):

  • 魔術師(火球): ①退却(自分が25%を下回ったら) ②敵集団の只中に固有能力を解き放つ(固有能力が使えるなら) ③④癒し手と召喚者を優先に固有能力を解き放つ(固有能力が使えるようになったら) ⑤最も傷の深い敵を攻撃(対象が35%を下回ったら) それ以外は、最も傷ついた敵を攻撃する。
  • 剣聖(抉り斬り): ①退却(自分が25%を下回ったら) ②最も近い敵に固有能力を解き放つ(数で劣るとき) ③癒し手と召喚者を優先に固有能力を解き放つ ④後衛(癒し手を含む)を攻撃(自分が60%を上回っている間) ⑤最も近い敵を攻撃(味方が敵の守りを崩した瞬間) それ以外は、最も傷ついた敵を攻撃する。
  • 癒し手(鼓舞の歌・再生): ①②③最も重傷の味方を回復(その味方が25%・40%・85%を下回ったら) ④退却(敵が接近したら) ⑤最も重傷の味方を回復(数で劣るとき、または戦闘開始直後の最初の10秒) それ以外は、最も近い敵を攻撃する。

出撃画面の上には勝率予想(例「分がある 突破の見込みは87–98% 死者は出にくい」)と、職業別のガンビットを保存している数(例「6職業中0職業に保存したガンビットあり」)が出ます。画面で確認

クラスの固有能力(signature)

技はマナ・フォーカス・スタミナ・怒り(rage)のどれかを消費します。指示画面に、技の効果・消費・クールダウンが表示されます。

  • 各職業の固有能力の名前と資源・再使用時間は職業と種族の表にあります。画面で確認
  • 番人: 固有能力は「踏みとどまれ」。戦闘開始時に怒りが20あり、消費も20なので、開幕から撃てます。歴戦になると第二の天命「旋風斬り」も選べます。
  • 僧侶の第二の天命「裁きの一撃」は、戦闘開始時から準備完了です(0.302)。聖騎士の第二の天命「按手」のような技はクラス共通の指示なので、その探索者の行の Edit から設定します。
  • ドルイド: 固有能力「再生」の回復は1.8倍(深まると2.2倍)。
  • 「シールドバッシュ」は守護者の第二の天命で、6秒ごとに出ます。画面で確認
  • 盾役の挑発は、敵の攻撃を盾役に引きつけます。守護者はスタミナに応じた一定のペースで、番人は殴る・殴られるほど早く溜まります。

組み方の例 推論

正確な条件名はゲーム画面に合わせて読み替えてください。

例1: HPが25%を切ったら下がる

  1. 条件「体力25%を割ったら」→ 生存(退却)
  2. 条件「技が準備完了」→ 技
  3. 最後の行「それ以外は」→ 攻撃

退却の行を一番上に置きます。下に置くと、攻撃の行が先に成立して逃げません。打たれ弱い魔術師・レンジャー向けです。盾役に付けると前線が崩れるので、盾役の退却ラインは低めにします。

例2: 固有能力が撃てるなら一番近い敵に撃ち込む

  1. 条件「技が準備完了」→ 技 → 標的「一番近い敵」
  2. 最後の行「それ以外は」→ 攻撃

技の行を最後の「それ以外は」の攻撃より上に置くのが絶対条件です。範囲技(旋風斬りなど)は、敵がまとまっているときに撃たないともったいないので、when outnumbered と組み合わせる手もあります。

例3: 癒し手の基本形

  1. 癒し手から見える位置にいる
  2. 回復(体力の低い味方を優先)
  3. 余裕があれば攻撃

攻撃役に「数で負けたら一番近い敵」の行を上に置くと、敵の癒し手を放置しがちになります。敵癒し手を先に落としたいなら、標的指定の行を上へ移します。

例4: 開幕で一人を集中して落とす

魔術師に「初手で攻める」(最初の12秒は全力で打つ)と「敵の射手・術者を狙う」を組みます。CNOTE では、最強の魔術師一人を軸にする All I need is a wizard という編成が紹介されています。

性格で指示が曲がる

探索者は性格に応じて指示を曲げることがあります。

  • 無謀な探索者は、足場を固める・戦線を守るといった指示を破ることがあります。推論(英語の Hold・Guard との対応)
  • 臆病な探索者は、体力60%以下だと「攻めに出る」を拒むことがあります。推論(英語の Press との対応)
  • 指示を曲げた結果なにかが起きると、出撃報告(debrief)に1件だけ書かれます。
  • 退却や引き返しのように絶対に守らせたい指示があるなら、無謀・短気・臆病の探索者には頼らないこと推論。泰然のリーダーは引き返す指示を正確に守ります。

一党全体の引き返す判断(リーダー)

日本語版では出撃画面の「隊長」タブにあります。画面で確認 「誰が率いる?」で隊長を選び(既定は「彼らに任せる」)、「常設の命令」で引き返すタイミングを決めます(例:「半数が倒れたら引き返す」)。ガンビットのタブにも同じ「引き返す時」があります。隊長タブにはほかに「送り出し」の言葉(何も言わない/落ち着かせる/鼓舞する/より多くを求める)と、隊長の特性による癖(例:「命じられたより一段早く引き返し、分かれ道では封じられた罠を避ける」)が出ます。常設の命令の選択肢は「なし」「最初の1人が倒れたら」「半数が倒れたら」「大半が倒れたら」。リーダーの気質で判断が前後し、勇敢・無謀なリーダーは遅め、臆病なリーダーは早めに決断します。冷静なリーダーは設定どおりに動きます。

部屋・マスごとの指示

  • 最後の部屋(ボス部屋): ほかの部屋とは別の指示を設定できます。試練でライバルの隊(部門により4〜6人)と当たるのもここです。
  • 隊形のマス: マスに専用の指示を付けられます。その指示は、書いたときのクラスにしか適用されません。
  • 保存: ガンビットは職業ごとに保存でき、出撃画面に保存している職業の数が出ます(上の「どこで設定するか」)。新人用にクラスの初期設定も保存できます。武具庫で保存・切り替えするのは装備のセットです。推論

結果の確かめ方

  • 戦闘をコマ送りで見ると、探索者のカードに「どの指示がなぜ発動したか」が表示されます(0.301)。
  • 出撃報告に、各探索者の指示が実際にどう働いたかが出ます(0.303)。
  • 出撃前の勝率予測は、実際の隊形と指示を使って計算されます。
開発者は ITCH で「新しい指示とクラスを追加する大改修」を予告しています。また、ルールを「通常行動」と「緊急時の反応」の2つのリストに分ける案(瀕死の味方への回復が下の行に埋もれないようにするため)も検討中とのことです。仕様が変わる可能性が高い分野です。
