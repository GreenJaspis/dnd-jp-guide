育成

訓練、熟練、誓い、学舎での見習い育成をまとめています。

体調の管理

状態・重圧・疲労の管理は状態のページにまとめています。

訓練: 1年目は研鑽中心

  • 鍛錬: 現在能力を素質に近づけます。若手(新参/伸び盛り)向け。
  • 研鑽: 指定した能力値を上げます。15を超えると1点ごとにコストが1.6倍。仕事に直結する弱点を埋めるのに向くので、1年目はこちらが有効という意見が多いです。
  • Mentor: 同じクラスの師匠だと効果1.3倍。師匠と一緒に潜ると学習+25%。
  • 訓練場の枠は最初2つで、施設レベル1ごとに+2。静養と稽古は枠を使いません。

訓練場の画面 画面で確認

日本語版の訓練場の凡例では、次の語が使われています。英語名との対応は説明の内容から当てたものです。推論

画面の語英語(推定)画面の説明(要約)
鍛錬鍛錬幅広く学ぶ。星へ向けて総合的な能力を上げ、多くの能力値を少しずつ伸ばす。若い者と師がつく者ほど速く、到達点に近いほど遅い。到達点では、職業が最も必要としない能力値から最も必要とする能力値へ点を移す。仕事は上がり、星は上がらない。

静養静養席は使わないが、そのあいだは鍛錬も研鑽もしない。基本は6日ごとに状態+14・重圧−14・疲労−12で、医師がいると増える(下の注を参照)。

師をつけるMentor熟練5以上で館にいる探索者は、ほかの者が鍛錬するあいだ教えられる。一人で鍛えるより遅くなることはなく、二人のあいだに絆が結ばれる。研鑽では、選んだ師が得意な能力値で助けになる。よい師は熟練と統率が高く、自分と同じクラスを最も速く教える。
  • 棒の見かたは3つ: 「能力」は総合的な実力で名簿と同じ星、「仕事」は役割をどれだけ果たせるか、「熟練」は次のレベルにどれだけ近いか。
  • 訓練場のタブ: 訓練・ガンビット・師匠・静養・集い・不在・成長記録・すべて。「手の空いた控えを自動で鍛える」を有効にすると、空いた席が埋まります。
  • 鍛錬(画面の説明): 能力が素質に向かって上がり、あわせてその天職が戦いに使う能力値が幅広く上がる。伸びしろの大きい若く未熟な者ほど速く、到達点に近づくにつれて遅くなる。到達点に達しても止まらず、クラスが最も必要としない能力値から最も必要とするものへ一点が移るので、仕事は上がり、星は上がらない。画面で確認
  • 指導を受けた: 若い探索者を「指導を受けた」に就けると、訓練のあいだ古参が教える。鍛錬と同じく席を一つ使う。教え手の腕に応じて弟子は一人から三人(指南役の役目にあればさらに二人)。熟練5未満の者は教えられず、館にいなければならない。同じクラスなら最も速く、同じ役割ならよく、別の職ならわずかしか加わらない。新参か伸び盛りのうちは、よい教え手が時おり素質を引き上げる。全盛からは、すでに持つ上限に届く手助けしかできない。師の傍らで闇へ降りた弟子は、同じ探索からより多くを学ぶ。画面で確認
  • 研鑽: 一度にひとつの能力値を鍛え、鍛錬が止まった後も各能力それぞれの上限まで続く。「自動」にしておけば、そのクラスで評価に最も重く響く十の能力値を順に鍛える。素質の等しい二人は、天職がなんであれ研鑽で同じ評価に届きうる。血族の傾き(種族の札の+−)は、その能力値の到達点を同じだけ動かす。画面で確認
  • 訓練ガンビット: 研鑽の席に、一つの能力値ではなく「能力値がある数値未満なら」という行の一覧を与えられる。訓練場はまだ満たされていない一番上の行に取り組み、席が二つなら上の二行に取り組む。一覧はプリセットとして保存でき、ほかの探索者にも使える。速くはならず、素質が定める上限も超えない。画面で確認
  • 師匠タブ: 教え役の一覧(熟練・統率、門下の人数、「教え役に残す」)、指導を受けている者、研鑽の指導が並びます。「師匠は自分の得意な能力値(13以上で、その探索者より上のもの)で研鑽を速める。『指導を受けた』と同じく、師匠の枠を一つ使う」。画面で確認
  • 自動の訓練では「今日は研鑽(席を2つ使う)」と出ることがあります。画面で確認
  • 静養の値と医師: 同じギルドで、凡例の数値が「+18/−18/−16」のときと「+14/−14/−12」のときがありました。画面で確認 後者は医師が戦乱に同行して館を空けていたときです。医師のカードの「回復+31%」を基本値に掛けると 14×1.31≒18、12×1.31≒16 になり、数字が合います。静養の基本値は+14/−14/−12で、医師の回復の効果で増えると考えられます。推論

熟練の段階 画面で確認

画面では「熟練」の欄に「初陣済み 6」「歴戦 14」のように、段階名と熟練の値が並んで表示されます。

熟練は、探索で得る点がたまると1ずつ上がります。画面の説明は「熟練は生きて帰った探索の数を表し、どれほど強く打つかは示さない」です。能力値は上がりませんが、訓練の効率が上がり(熟練 20で1.25倍)、倒れたときに致命傷になりにくくなります。

点の入り方 画面で確認

  • 点は探索でしか得られません。
  • 生きて帰れば1点。探索が6日以上かかったなら、さらに1点。隊が踏破できなかったなら、さらに1点。
  • 例: 5日の探索を途中で棄権して帰ると、結果の画面に「生還者それぞれに熟練+2」と出ます(生還1点+踏破できなかった1点)。
  • 踏破できなかった探索のほうが熟練の点は多く入ります。ただし、探索での能力の成長は「踏破できなかった探索は、ほとんど何も教えない」とされています(ダンジョンと状態)。

誓い

  • 探索者ごとの個人的な目標です。経歴・最後の戦い・特定の獲物・場所や奉仕・後世に残すこと・人間関係・ギルドの達成・宿敵など、約10種類あります。
  • 果たすと士気・忠誠・名誉が上がり、美徳の特性が付きます。名のある魔物を倒す誓いでは、戦利品も出ます。
  • ほかのギルドに惜敗したあとに誓うこともあり、ライバル関係が熱くなります。
  • 長く引き留めたい探索者や、The Chronicle の物語を楽しみたいプレイに効きます。

能力値30種と特性の一覧は用語集にあります。

学舎での見習いの設定

見習いごとに、次の3つを設定します。プレイ報告

設定中身
誰に師事するか担当の導き手を選びます。導き手は学舎の段階ごとに1席。同じ導き手に付け続けると、その特性が受け継がれます(Mentor's Word)。
どの能力値を伸ばすか伸ばしたい能力値を指定します。
直近の約束をするか出陣などの約束をするかどうか。

パッチノートで確認できた学舎の仕組み:

  • 毎年の新入生は6〜7人で、名前の付いた学年になり、学年の中に友情とライバル関係が生まれます(0.302)。
  • 新入生の能力の上限は、ギルドの名声と学舎の評判で決まり、だいたい今の主力の強さあたりになります(0.303)。
  • 見習いカードには、信念が非情寄りか高潔寄りかと、天才児(Generational talent)かどうかが表示されます(0.301)。
  • 学舎の責任者(Keeper)を選べます。熟練が道慣れの探索者は、見習いを1季節のあいだ従者として連れて行けます。季節の終わりに、従者が受け継いだ信念か特性が記録されます。
  • 見習いを同盟ギルドに1季節預けたり、町の子どもの後見人になったりできます。4年目に引き受けた子どもは7年目に加わります(0.302/0.303)。
  • 職員の Mentor は、0.303で導き手に名前が変わりました。教え方は1対1です。導き手は手が空くと訓練場で若手を教えます。ボタン1つで、空いている導き手それぞれに一番伸びる探索者を割り当てられます(若手が優先)。
  • 誓約を結んだ年の見習いは売れません。
  • 伝承師がいないときは、導き手が Fog の中で新入生を見立てます。
  • 職員の導き手(Guide、旧 Mentor)は、学舎のレベル1ごとに1席。スキル50で見習いが導き手の特性を受け継ぎ、80で4つから選べます。
  • およそ20人に1人、生まれつき訓練の上限を超える才能を持つ探索者がいます(見習いの Generational talent 表示)。
  • 自前育成は時間がかかる割に効率が悪い、という意見もあります。itch.io のフォーラムの報告(ブラウザ版)では、4つ星の逸材が5季節で48→60と12点しか伸びませんでした。単一出典

学舎の画面 画面で確認

  • 学舎を預かる者: 画面の例では、武術指南が教えを受け持っていて、学舎の席に就いた導き手がいれば代わりに預かれる、と表示されていました。預かる者は見習いの伸びる速さを決め、受け入れの前に報告をくれ、見習いのおよそ3人に1人を形づくり、自分の信念か特性の一つを受け継がせます。画面の例では、授業は基本の1.4倍、導き手が預かれば1.3倍の速さでした。
  • 学舎が探す相手: 毎年の志願者の半分が、選んだ種族から来ます(例:「家門の二つの種族どちらも」)。
  • 学舎の評判: 100点満点(画面の例は29で「あまり知られていない」)。評判によって、入学する見習いが最大4%良くなります。
  • 町の子: 町の子を150Gで後見できます。
  • 入団選考: 年に6〜7人を受け入れます。学舎のない館は1〜2人です。
  • 教え: 学舎の見習いは、学舎のない館の4.6倍の速さで能力を伸ばします。ただし年齢が許す上限は超えません。
  • 誰の耳に届くか: 毎年の入学に一世代に一人の逸材が現れる見込み(画面の例では9%)。
  • 導き手たち: 学舎の段階ごとに導き手の席が1つあります。導き手のカードには技量・給金・固有の能力(例:「教えの系譜」)・効果(例:「指導を受けた修練+10%」)が出ます。空いた席からは「師範を探す」で探します。
  • いま学舎にいる者: 見習いごとに、従者として仕える相手・期間・学ぶ役割・約束を設定します。送り出した見習いは、決まった日数のあとに誓約を結びます。

探索者の詳細画面 画面で確認

名簿から探索者を開くと出る画面です。タブは「戦い」「物語」「数値」で、「全ページ」で全部を続けて見られます。例は6年目のティーフリングの魔術師(熟練 歴戦14)の画面です。

見出しの部分

  • 名前と二つ名(例「災いなす者」)、札(役割・年齢の段階・伸びの向き)、能力と素質の星。
  • 年齢の段階の隣の札は、伸びの向きを表します。順に まだ登っている → 全盛 → 曲がり角 → 盛りを過ぎた の4段階です。プレイ報告 画面で見た組み合わせ: 伸び盛り・まだ登っている/円熟・全盛/円熟・曲がり角/古参・盛りを過ぎた。画面で確認 同じ円熟でも札が違うので、年齢の段階だけでは決まらないと考えられます。推論 年齢の段階(新参 → 伸び盛り → 全盛 → 円熟 → 古参 → 黄昏)にも「全盛」がありますが、別のものです。
  • 魔獣の探索者は、種族の代わりに魔獣の型と「従える魔獣」が出ます(例「粗暴者・剣聖・従える魔獣・資源:持久力」「深部で鍛えられた」)。学舎の見習いは「あなたの学舎に在籍中、6年」のように出ます。画面で確認
  • 種族・職業・資源(例: 魔力)、生まれ(例「灰の境域、堅壁の生まれ」)、今どこにいるか(例「探索からの帰路。6年・緑潮・15日に戻る。」)。
  • 年齢、現役の年齢(種族で決まる。例: 18〜42歳)、熟練、誓約の残り年数、給金(例: 6日ごとに28G)。

戦い

  • 割り当てられた役割: 役割と評価(例「攻撃役 82・本来の役割」)。就けない役割もあります(例「魔術師に治癒の席は開かれていない。癒やしは生まれつきの才であり、訓練で得られるものではない。」)。
  • 役目: 名簿のグループ(例「先鋒隊 最初に闇へ踏み込む者。」)。
  • 概要: 瞬発の数値と、攻勢・機動・生存力の星。戦闘での体力・毎秒のダメージ・命中・回避。
  • 会心率・防御率・被害軽減には「現在」「能力値の上限」「装備込みの天井」の3つが並びます(例: 会心率 33%・35%・60%)。能力値を上げきって届くのは上限まで、その先は装備で伸ばす、と読めます。推論
  • 装備による上乗せ(例: 攻撃力+31%・被害軽減+5%・会心率+8%・命中+2)と、戦績(探索・与ダメージ・撃破・倒れた回数・館への稼ぎ。合計と探索一回あたり)。
  • 今の状態: 士気・状態・重圧・疲労。
  • 装備: 武器・防具・装身具の3枠。「標準のクラス装備に加わる追加装備」です。探索に出ているあいだに選ぶと取り置かれ、帰った日に身につけます。
  • 戦い方: 特性と第二の天命の札が並びます(例: 謙虚・血縁の誇り・秘術の槍)。

物語

  • 近ごろ(最近の出来事の一文)と、館が知っていること。
  • 人物: 信念・傾き・誓い・欠点・遺恨。誓いには進み具合が出ます(例「誓ってから倒した獣: 32/35」)。
  • 絆: ほかの探索者とのつながりが並び、カーソルを合わせると種類と値が出ます(例「親友・61・指導している相手」)。
  • 経歴: 出撃回数・依頼回数・年の奉公・栄誉と、年ごとの表(探索・試練・依頼・戦争・撃破・与ダメージ・被ダメージ・治癒・倒れた回数)。ギルドの中での順位も出ます(例「このギルドの探索数で第4位」)。
  • 栄誉、ギルドが覚えていること、歳月がこの者にもたらしたもの(例「第3年 第二の天命: 秘術の槍」)。
  • 闇での功績: 倒した敵にちなむ称号(例: 陣破り・鉄甲砕き・鼠捕りII・影狩り・散兵狩り)。敵の型ごとに決まった数を倒すと称号が得られ、進み具合が出ます(例「歩兵の敵: 93/110体を倒した。110体で称号を得る。」)。
  • 当時と今: 加入した日と今日の能力値の比較。年ごと: 各年の終わりの評価と、最も動いた能力値。

話す・この者への方針

  • 「話をする」「褒美を与える」。届いた言葉は、抱えている遺恨に触れ、ときに和らげることがあります。
  • 「この先の道について話す」: 留め置く・申し出を受け付け中・市場へ。
  • この者への方針: 育てる・休ませる・取引で先に出す・手放す。帰館時に手放すこともできます。

数値

能力値30種が戦闘・精神・身体・役割の4つに分かれて並びます。「上限」を押すと、今の値と上限が出ます(例: 鎧の扱い 18/20、勇気 16/16)。名前は用語集の能力値と同じです。
